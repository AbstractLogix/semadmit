# Security policy

Semadmit is experimental. It has no published package or supported binary release. The Python claim result verifier checks deterministic result structure and bindings. It does not authenticate evidence sources, prove claim truth, or verify source independence.

## Report a vulnerability

Use GitHub's private vulnerability reporting feature for this repository when it is enabled. Do not include vulnerability details in a public issue.

If private reporting is not available, open an issue that only asks maintainers for a private reporting channel. Do not include a proof of concept, affected secrets, or other vulnerability details in that issue.

Please include the affected Semadmit revision, runtime and platform, impact, and a small reproduction after maintainers provide a private channel. Use invented or public data. Do not send real credentials or private evidence.

## Scope

Reports may cover Semadmit source, its documented protocols, and its maintained build workflow. Reports about an external provider or dependency should identify the affected component and version. The project does not promise a response time or security support period for an unreleased version.
